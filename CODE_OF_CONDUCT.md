# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment
of any kind is not accepted in issues, pull requests or any other project space.

To report a problem, open a
[private security advisory](https://github.com/LorenzoColombani/openbots/security/advisories/new) marked "conduct", or
contact the maintainer through their GitHub profile. Reports are read in
confidence.
